# 0005 KaTeX 在构建时渲染

## 状态

已采纳。

## 背景

数学公式需要可访问、可打印、无客户端 JS。MathJax 客户端渲染会增加脚本和布局抖动。

## 决策

用 `remark-math` + `rehype-katex` 在构建时输出 HTML + MathML。解析时标记 `hasMath`，主题只在该页面加载 KaTeX CSS。公式错误让构建失败。

## 后果

- 数学页面零客户端 JS，首屏稳定。
- KaTeX CSS 和字体只在需要时加载；资源放在共享 vendor 目录。
- 构建时间略增，公式错误会阻断发布。
- 搜索索引排除公式节点，避免符号串污染结果。
