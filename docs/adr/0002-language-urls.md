# 0002 中文根路径，英文 /en/

## 状态

已采纳。

## 背景

默认语言需要在根路径，否则中文 URL 会多一层 `/zh/`。两种语言同时存在时，还要避免重复内容和错误 hreflang。

## 决策

- 默认语言中文发布在站点根路径。
- 其他语言加 `/<lang>/` 前缀。
- 不生成 `/zh/`，不做浏览器语言自动跳转。
- `hreflang` 输出 `zh`、`en` 和 `x-default`，`x-default` 指向中文根。
- 项目页部署时“根”是 `https://<user>.github.io/<repo>/`，由 `base` 注入。

## 后果

- canonical、链接 helper 和 sitemap 只有一套规则。
- 根路径永远是中文，英文用户通过显式语言链接进入 `/en/`。
- 语言切换器在没有译文时退回对应语言的首页。
