# 主题截图

截图来自本地构建，1280×900，浏览器为暗色偏好。三套主题都支持亮/暗模式。

## folio

独立杂志 / 文学期刊。衬线正文、大留白、细规则线，右侧目录。

![folio 首页](screenshots/folio-home.png)

![folio 文章页](screenshots/folio-post.png)

移动端：

![folio 移动端](screenshots/folio-mobile.png)

适合：长文、随笔、排版笔记、个人写作。

## orbital

70 年代末技术手册 / CRT 终端。等宽元信息、技术网格、编号章节、磷光琥珀色。

![orbital 首页](screenshots/orbital-home.png)

![orbital 文章页](screenshots/orbital-post.png)

适合：工程日志、系统笔记、带代码和公式的技术文章。

## scholar

期刊论文 / 学位论文。摘要、编号章节、左侧目录、正文衬线。

![scholar 首页](screenshots/scholar-home.png)

![scholar 文章页](screenshots/scholar-post.png)

适合：研究笔记、文献综述、数学和理论性文章。

## 选择建议

- 先确定主要读者和文章类型，再选主题；不要按颜色选。
- 主题可以随时切换，内容不需要改。
- 新增主题前先读 [theming.md](theming.md) 和 [design-review.md](design-review.md)。
