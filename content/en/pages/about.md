This is a place for notes on engineering, typography, and maintenance. Posts aim for concrete problems and reusable practices rather than general lessons.

The site is built by the static generator in this repository, written in Markdown, and deployed to GitHub Pages. Theme, languages, domain, and author information live in `site.config.ts`.

To reuse the system, create a repository from the GitHub Template, run `npm run setup`, and replace `content/`.
